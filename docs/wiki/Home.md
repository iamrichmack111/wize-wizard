# Wize Wizard Wiki

Wize Wizard is a strategy-learning, decision-analysis, and execution workbench that turns an uncertain goal into a structured project plan.

![Project lifecycle](../images/diagrams/project-lifecycle.png)

## Core workflow
1. Define the project.
2. Answer the five strategic questions.
3. Use `I need to ___ so that I can ___`.
4. Build the Need → Wish → Dream → Fantasy chain.
5. Estimate with PERT.
6. Create tasks and a communication plan.
7. Record evidence.
8. Produce the final Project Plan.

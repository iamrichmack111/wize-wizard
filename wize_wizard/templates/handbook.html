Read the strategy reference without leaving Wize Wizard.

The handbook is a reference layer for the Wize process. It treats strategy as judgment + economics + logic + computation, and repeatedly asks what must be true before a framework applies. Read a concept here, then return to your project and turn it into an I need to… so that I can… statement.

HOW TO USE IT

Read → understand → apply → test

  1. 1

    Read the plain-English meaning. Do not begin with the formula.

  2. 2

    Read the syllogism and worked example. Identify the assumptions.

  3. 3

    Check “Use it when” and limitations. Decide whether the framework actually fits your case.

  4. 4

    Return to Wize. Convert the conclusion into a Need goal or a Why-ladder statement.

  5. 5

    Test execution. Use PERT, tasks, communications and reports to see whether the strategy can actually be delivered.
